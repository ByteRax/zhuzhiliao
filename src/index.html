竹知了是什么？

竹知了也叫竹蝉、拉线蝉或知了哇呜，是一种甩起来会发出“哇哇”声的传统民间玩具。这个页面是它的零依赖网页模拟版，也就是网友说的赛博竹知了，支持手机和电脑浏览器直接打开。

怎么玩竹知了？

  1. 按住画面中的竹签。
  2. 沿圆圈方向甩动，转速越高，声音越响越急。
  3. 也可以点击“自动甩”，或在支持的手机上使用“甩手机”体感模式。

竹知了为什么会哇哇叫？

真实玩具用涂有松香的线连接竹膜和竹签。甩动时，松香线发生黏滑摩擦，振动传到竹膜，再由竹筒空腔共鸣放大。本模拟使用绳系质点物理、Canvas 2D 和 Web Audio，并优先播放真实竹知了录音采样。

设备与兼容性

现代桌面和移动浏览器均可游玩，需要 JavaScript、HTML5 Canvas 和 Web Audio。手机体感模式需要 HTTPS 或本地文件，并可能需要授权动作传感器；WebGL 不可用时会自动回落到 2D 画面。

常见问题

竹知了需要下载安装吗？
不需要。页面无需构建或安装依赖，浏览器直开即可玩，主页面也支持保存后离线打开。
为什么第一次没有声音？
浏览器通常要求用户先点击或触摸页面才能播放声音；点一下页面或“点一下开声”即可解锁。
手机为什么不能使用甩手机模式？
该模式依赖动作传感器，需要 HTTPS 或本地文件，并且 iPhone 可能需要在首次使用时授权。
竹知了是什么玩具？
竹知了是中国传统民间玩具，各地也叫竹蝉、拉线蝉、知了哇呜。竹筒一端蒙竹膜，膜心系一根涂松香的线，线另一端拴小竹签；抓着竹签甩圈时线在松香上黏滑摩擦，带动竹膜振动、竹筒空腔共鸣，发出酷似蝉鸣的“哇哇”声。
什么是赛博竹知了？
“赛博竹知了”是网友对这类竹知了网页模拟版的叫法：不用买真的竹筒玩具，在浏览器里按住画圈甩起来就能听见一模一样的“哇哇”声，声音来自真实竹知了录音采样。
竹知了收费或有广告吗？
完全免费，无广告、无内购、无需注册，代码开源在 GitHub。
竹知了的声音是合成的还是真实录音？
主音源是真实竹知了玩具的录音采样，随转速改变回放速率；采样解码失败时才回退到 Web Audio 合成音。
可以离线玩吗？
可以。Service Worker 会缓存核心资源，也能“装进桌面”作为 PWA 使用。
竹知了会收集我的数据吗？
只统计匿名的全站哇数、访问数与在线人数；个人哇数仅存在浏览器本地，不收集个人身份信息。
